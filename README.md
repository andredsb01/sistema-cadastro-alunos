# Sistema de Cadastro de Alunos

Sistema simples de cadastro de alunos em Python, executado pelo terminal. O projeto foi desenvolvido durante meus estudos de programação.

## Funcionalidades

- Adicionar alunos
- Listar alunos cadastrados
- Buscar alunos pelo nome
- Remover alunos
- Calcular a média geral das notas

## Recursos utilizados

- Python 3
- Listas e dicionários
- Funções, condicionais e laços de repetição
- Tratamento de exceções

## Como executar

Tenha o Python 3 instalado e execute:

```bash
git clone https://github.com/andredsb01/sistema-cadastro-alunos.git
cd sistema-cadastro-alunos
python main.py
```

O projeto pratica conceitos fundamentais de Python, organização de código por funções e manipulação de estruturas de dados.
