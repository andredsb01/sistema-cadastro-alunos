Sistema de Cadastro de Alunos

Um sistema simples de cadastro de alunos desenvolvido em Python, executado diretamente pelo terminal.

Este projeto foi desenvolvido como parte dos meus estudos de programação, com o objetivo de praticar conceitos fundamentais da linguagem Python.

Funcionalidades

Adicionar alunos
Listar alunos cadastrados
Buscar alunos pelo nome
Remover alunos
Calcular a média geral das notas

Recursos utilizados

Python 3
Listas e dicionários
Funções
Estruturas condicionais
Estruturas de repetição
Tratamento de exceções

Como executar
Tenha o Python 3 instalado.

Clone este repositório:
git clone URL_DO_SEU_REPOSITORIO

Entre na pasta do projeto:
cd sistema-cadastro-alunos-python


Execute o programa:
python main.py
